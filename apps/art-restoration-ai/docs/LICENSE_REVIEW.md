# Lizenzprüfung – Pflichtregister

Vor jeder Veröffentlichung oder kommerziellen Nutzung müssen Code, Gewichte, Trainingsdaten,
Plugins, Container und Abhängigkeiten getrennt geprüft werden.

| Komponente | Vorläufiger Hinweis | Freigabestatus |
|---|---|---|
| Eigener Plattformcode | zunächst proprietär oder später gewählte Lizenz | Entscheidung offen |
| Real-ESRGAN | Upstream-Code BSD-3-Clause; Gewichte separat prüfen | Prüfung offen |
| SwinIR | Upstream-/Checkpointbedingungen einzeln prüfen | Prüfung offen |
| GFPGAN | Upstream-/Checkpointbedingungen einzeln prüfen | Prüfung offen |
| BasicSR | Apache-2.0-Projekt; enthaltene Komponenten separat prüfen | Prüfung offen |
| libvips | LGPL-2.1-or-later | Prüfung offen |
| Topaz | bestehende Endnutzerlizenz; API-/CLI-/Cloudrechte nicht unterstellen | Herstellerprüfung offen |

Dieses Register ist keine Rechtsberatung und keine pauschale Lizenzfreigabe.
